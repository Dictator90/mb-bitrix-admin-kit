# ID

Класс: `MB\Bitrix\AdminKit\Field\ID`.

Назначение: идентификатор сущности.

## Доступные методы

Специфичных fluent-методов у `ID` нет.

Общий API `Field`: [field.md](field.md).

Особенность:
- скрыт на form-странице.

Пример:
```php
ID::make('ID');
```

## Значения по умолчанию

- `label = "ID"`
- `column = "ID"`
- Поле скрыто на `form` по умолчанию.
