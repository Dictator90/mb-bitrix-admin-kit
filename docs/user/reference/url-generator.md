# Reference: UrlGenerator

## Назначение

`MB\Bitrix\AdminKit\Support\UrlGenerator` строит admin URL без ручной сборки query string.

## Основные методы

- `resourceUrl()`
- `pageUrl()`
- `createUrl()`
- `editUrl()`
- `detailUrl()`
- `actionUrl()`
- `bulkActionUrl()`
- `exportUrl()`
- `importUrl()`
- `endpointUrl()`

## Ограничения

- Не собирайте URL вручную в page/menu/routing слое.
